# Rede Credi: Conexão Financeira

Crie um site institucional moderno, profissional e focado em conversão para uma empresa de crédito consignado chamada Rede Credi.

O objetivo principal do site é gerar contatos via WhatsApp e transmitir confiança, credibilidade e rapidez no atendimento.

Estilo desejado

O site deve transmitir a sensação de uma fintech moderna, confiável e acessível, evitando o visual tradicional de bancos antigos. O foco é converter visitantes em contatos, destacando rapidez, transparência e atendimento humanizado, com uma interface premium que gere confiança desde o primeiro acesso.
